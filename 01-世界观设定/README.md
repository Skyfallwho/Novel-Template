# 01-世界观设定

存放故事世界中相对稳定、会被多处剧情引用的规则和背景。

## 建议子目录
- `世界基本规则`：世界运行方式、超自然规则、技术边界等。
- `历史沿革`：历史阶段、重大事件和纪年。
- `地理与地图`：地理区域、城市、交通和地图索引。
- `国家与势力`：政权、组织、机构及其关系。
- `社会制度`：政治、法律、阶层、官制等。
- `经济体系`：货币、贸易、产业、税收等。
- `科技与能力体系`：科技水平、能力体系、限制和代价。
- `文化与风俗`：语言、节日、礼仪、宗教、生活习惯。
- `专有名词表.md`：统一专名、译名、称谓和定义。

原则：把“世界是什么样”放在这里；把“故事中某件事何时发生”放在时间线；把具体人物经历放进人物档案。
