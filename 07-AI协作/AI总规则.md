# AI协作总规则

你正在协助作者处理一部长篇小说。请把本仓库视为项目资料的权威来源。

## 一、开始任务前

1. 阅读根目录 `README.md`。
2. 阅读 `00-项目管理/写作规范.md` 和 `00-项目管理/当前进度.md`。
3. 根据本次任务读取相关人物档案、世界观设定、剧情大纲、伏笔记录和必要的前文。
4. 回复中列出实际读取的文件路径。没有读取的资料不要声称已经核对。

## 二、事实与建议分开

将信息区分为：
- **已确定事实**：项目文件明确记录的内容。
- **本次建议**：AI 新提出、尚未被作者确认的方案。
- **待确认问题**：资料缺失、相互冲突或存在歧义的内容。

不得把推测、临时构思或常见套路冒充项目既定设定。

## 三、保持连续性

重点核对：
- 人物身份、年龄、关系、生死、伤病、能力和所在位置。
- 时间、地点、交通、事件先后与人物行动轨迹。
- 世界规则、制度、经济数据和专有名词。
- 已埋设伏笔、已回收伏笔和前文承诺。
- 当前卷大纲与全书主线。

## 四、执行修改

- 严格遵守 `00-项目管理/写作规范.md`。
- 不擅自更改人物姓名、核心设定、既定剧情和章节编号。
- 未经明确要求，不批量修改无关文件。
- 修改正文时保留原文件名和章节编号。
- 如发现必须修改既有设定，先说明原因、影响文件和连锁影响，等待作者确认。
- 不要制造“最终版2”等重复版本；版本历史由 Git 管理。

## 五、交付格式

任务完成后说明：
1. 完成了什么。
2. 读取了哪些文件。
3. 修改了哪些文件。
4. 新增了哪些设定或建议（标明待作者确认）。
5. 发现了哪些连续性问题。
6. 下一步需要作者决定什么。

## 六、作者拥有最终决定权

所有剧情方向、人物命运、世界观设定和正式写作规则，以作者明确确认的内容为准。
