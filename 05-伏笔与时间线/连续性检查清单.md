# 连续性检查清单

每次完成重要章节或剧情段落后，按需检查。

## 时间
- [ ] 日期、时辰、季节和事件先后顺序一致
- [ ] 人物移动所需时间合理且符合设定
- [ ] 年龄、任职年限和经历时长一致

## 空间
- [ ] 人物所在地点与上一场景衔接
- [ ] 地理距离、路线和交通条件一致
- [ ] 场景中的物品位置没有无故变化

## 人物
- [ ] 人物生死、伤病、体力和能力状态一致
- [ ] 人物称谓、身份和关系一致
- [ ] 人物掌握的信息符合其经历

## 物品与资源
- [ ] 重要物品的持有人、位置和状态一致
- [ ] 金钱、资源、库存和消耗有记录
- [ ] 特殊能力的使用条件与代价一致

## 剧情
- [ ] 前文承诺和伏笔已登记
- [ ] 重要事件的原因与结果衔接
- [ ] 新设定没有悄悄推翻旧设定
